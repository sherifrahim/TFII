## How to take them

1. Open the live site (https://threatintel.mooo.com/ui/)
2. Resize browser to roughly 1440px wide
3. Take a screenshot of just the main content area (not the whole browser chrome)
4. Save as PNG to this directory with the filenames above

Once all five PNGs are added, delete this README.md.
